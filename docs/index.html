Docker container utility, management tool, and helper scripts

Install

Oneliner bootstrap

curl -fsSL https://raw.githubusercontent.com/joshuacox/roustabout/master/bootstraproustabout.sh | bash

Manual install

Clone the repository and install using Make:

git clone https://github.com/joshuacox/roustabout.git
cd roustabout
sudo make install

To install to a user directory without root:

make install PREFIX=$HOME/.local

Unified CLI (roustabout)

Roustabout provides a single command dispatcher for managing Docker containers:

Usage:
  roustabout <command> [arguments]

Commands:
  last [enter|logs|id]   Operate on the last spawned container (default: enter)
  enter [container_id]   Enter container with /bin/bash (fallback: /bin/sh)
  logs [container_id]    Follow logs of container (default: last spawned)
  kill [--all | id...]   Kill specified container(s), or all running with --all
  krm <id...>            Kill and remove container(s)
  clean [options]        Clean Docker resources (--all, --volumes, --stale, --images, --containers)
  clean-volumes          Remove dangling volumes
  stale                  Prune unused images older than 24h
  openvpn-creds <client> Generate OpenVPN client credentials using kylemanna/openvpn
  version                Show version information
  help                   Show this help message

Legacy Aliases (100% Backward Compatible)

All classic standalone script names are preserved and work alongside roustabout:

Last Container Operations

  • LastDocker — Shell into the last container that spawned.
  • LogDockerLast — Stream logs from the last spawned container.

Container Management

  • EnterDocker [id] — Exec bash/sh inside a container.
  • KillDocker [id...] — Kill running containers safely.
  • KRMdocker <id...> — Kill and remove container(s).

Cleanup & Pruning

  • CleanDocker — Clean stopped containers and dangling images safely.
  • CleanOrphanedVolumes — Clean dangling volumes.
  • StaleDocker — Prune unused images older than 24 hours.

OpenVPN Helper

  • createOpenVPNdockercreds <clientname> — Used with kylemanna/docker-openvpn to generate client .ovpn profiles.
